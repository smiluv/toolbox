About these tools

The CSS generators give you a live preview while you drag sliders, then the exact CSS to copy into your stylesheet. The security tools use the Web Crypto API built into your browser, so passwords and IDs are generated on your device and never transmitted.

Frequently asked questions

Are the generated passwords really random?

Yes. They come from crypto.getRandomValues, the browser's cryptographically secure random number generator, with no bias between characters.

Is MD5 safe for storing passwords?

No. MD5 and SHA-1 are fine for checksums but not for passwords. Use a slow password hash such as bcrypt or Argon2 on your server.

Does the CSS work in all browsers?

The generated CSS uses standard properties supported by all modern browsers, including box-shadow, gradients, border-radius and @keyframes.
