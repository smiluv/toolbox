About these text and code tools

These utilities cover the small jobs writers and developers do every day: checking a word limit, fixing letter case, de-duplicating a list, pretty-printing an API response, encoding a token or testing a regular expression. Nothing is uploaded, so you can paste confidential text, logs or JSON safely.

Frequently asked questions

Is it safe to paste private JSON or text here?

Yes. All processing happens in your browser; nothing is sent to a server or stored.

Which tool should I use to fix invalid JSON?

The JSON formatter and validator shows a clear error message for the first problem it finds, and can beautify or minify valid JSON.

Does the regex tester use JavaScript regex syntax?

Yes. It uses your browser's JavaScript engine, with standard flags such as g, i and m, and highlights every match and capture group.
