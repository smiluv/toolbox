Encode text to Base64 or decode Base64 back to text, with full Unicode support.

What is Base64?

Base64 represents binary data using 64 printable characters (A–Z, a–z, 0–9, + and /). It is used to embed images in CSS, send attachments in email and pass data in JSON or URLs. Text is converted to UTF-8 bytes first, so any language and emoji work correctly.

Frequently asked questions

Is Base64 encryption?

No. Base64 is an encoding, not encryption. Anyone can decode it, so never use it to protect passwords or secrets.

What is URL-safe Base64?

It replaces + with - and / with _ and drops the = padding, so the result can be used in URLs and file names without escaping.
