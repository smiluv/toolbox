How to use the JSON formatter

Paste or type JSON on the left. It is parsed with the browser's native JSON parser, so the validation is exact. Choose beautify for readable, indented output or minify to remove all whitespace for production. Stringify turns the JSON into a single escaped string you can paste into code.

Frequently asked questions

Why is my JSON invalid?

The most common causes are trailing commas, single quotes instead of double quotes, unquoted keys and comments. Standard JSON allows none of these.

Is my JSON sent to a server?

No. Formatting and validation happen entirely in your browser, so it is safe for API keys and private data.
