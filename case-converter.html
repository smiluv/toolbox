Case Converter

Paste your text and click a button to change its case. Each line is converted separately.

When to use each case

Title Case is used for headlines, Sentence case for normal text, camelCase and PascalCase for JavaScript and C# names, snake_case for Python and databases, kebab-case for URLs and CSS classes, and CONSTANT_CASE for constants.

Frequently asked questions

What is the difference between camelCase and PascalCase?

camelCase starts with a lowercase letter (myVariableName); PascalCase starts with a capital (MyVariableName).

Does it work with accented and non-English letters?

Yes. The converter uses Unicode-aware rules, so letters like é, ü and ç are handled correctly.
