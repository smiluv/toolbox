How CSS animations work

  
@keyframes defines the styles at points from 0% to 100%. The animation shorthand then applies it to an element with a duration, timing function, delay, iteration count, direction and fill mode. Animating transform and opacity gives the smoothest performance.

  
Frequently asked questions

  
How do I make an animation loop forever?
Set the iteration count to infinite. Use alternate direction for a smooth back-and-forth motion.

  
Should I respect reduced motion settings?
Yes. Wrap large animations in @media (prefers-reduced-motion: no-preference) so users who are sensitive to motion are not affected.
