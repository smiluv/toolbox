Secure Password Generator

Generate strong, random passwords in your browser using cryptographic randomness.

How secure are these passwords?

Characters are chosen with crypto.getRandomValues(), the browser's cryptographically secure random number generator, without modulo bias. Every selected character type is guaranteed to appear. Strength is shown as entropy in bits: 80+ bits is very strong.

Frequently asked questions

How long should a password be?

At least 12–16 characters for online accounts, and 20+ for master passwords or encryption keys. Length matters more than complexity.

Is it safe to generate passwords online?

With this tool, yes: the password is created on your device and never sent over the network or stored. Save it in a password manager.
