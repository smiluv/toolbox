Random Number Generator

Generate random whole numbers within any range.

—

How it works

Numbers are generated with crypto.getRandomValues() using rejection sampling, so every value in the range is equally likely. With "No repeats" each number can appear only once, which is perfect for lottery picks and raffles.

Frequently asked questions

Is this random number generator truly random?

It uses your operating system's cryptographically secure random source, which is suitable for draws, games and security purposes.

How do I pick lottery numbers?

Set the range of your lottery (for example 1 to 49), enter how many numbers are drawn, keep "No repeats" on and tick "Sort results".
