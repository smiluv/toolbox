About hash functions

A hash function turns any input into a fixed-length fingerprint. The same text always gives the same hash, and a tiny change gives a completely different one. Text is hashed as UTF-8 using the open-source CryptoJS library.

Frequently asked questions

Is MD5 still secure?

No. MD5 and SHA-1 are broken for security purposes and should only be used for checksums. Use SHA-256 or better for integrity checks.

Can I store passwords as SHA-256 hashes?

No. Passwords need a slow, salted algorithm such as bcrypt, scrypt or Argon2. Fast hashes like SHA-256 are too easy to brute-force.

Can a hash be reversed?

No. Hashes are one-way functions. Short or common inputs can still be guessed using lookup tables, which is why salting matters.
