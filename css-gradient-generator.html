CSS gradient types

  
linear-gradient() blends colors along a straight line at any angle, radial-gradient() spreads them outward from the center, and conic-gradient() sweeps them around a center point like a color wheel. The middle color is optional.

  
Frequently asked questions

  
Do CSS gradients work in all browsers?
Linear and radial gradients work in every modern browser. Conic gradients work in all current browsers. A solid fallback color is included for very old ones.

  
Are gradients better than background images?
Yes, for simple color blends. They scale to any size, need no download and are easy to change.
