Frequently asked questions

What is Markdown?

Markdown is a lightweight formatting syntax that turns plain text into HTML. It is used for README files, documentation, blogs and chat apps.

Can I paste the HTML into my website?

Yes. Copy the HTML output and paste it into any web page, CMS or email template.
