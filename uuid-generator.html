UUID / GUID Generator

Generate random version 4 UUIDs (also known as GUIDs) in bulk.

What is a UUID v4?

A UUID is a 128-bit identifier written as 32 hexadecimal digits, like 3f2b8c1e-9d4a-4f6b-a1c2-7e8d9f0a1b2c. Version 4 UUIDs contain 122 random bits generated here with crypto.getRandomValues(), so collisions are practically impossible.

Frequently asked questions

Is a GUID the same as a UUID?

Yes. GUID is Microsoft's name for the same 128-bit identifier format.

Can two UUID v4 values ever be the same?

In theory yes, but you would need to generate billions per second for many years to have a realistic chance of a single duplicate.
